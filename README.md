# Análise Estufas de Fumo - App de Multiagentes (Lean Six Sigma)

App em Streamlit que usa 3 agentes de IA (Coletor, Analista Six Sigma, Redator) para
analisar dados de lotes das estufas de fumo e gerar relatórios com causas raiz e
recomendações.

## Como usar
1. Abra o link do app
2. Cole sua chave de API da OpenAI na barra lateral (fica só na sua sessão, não é salva)
3. Envie o CSV/Excel dos lotes (ou cole os dados manualmente)
4. Clique em "Analisar dados"
5. Baixe o relatório gerado

## Observação sobre a chave de API
A chave de API não fica salva em nenhum lugar — você digita toda vez que abre o app.
